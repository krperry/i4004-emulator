Intel 4004 Lessons

On 15 November 1971 Intel announced the 4004, the first microprocessor sold to the public. It was a whole computer brain on one chip, about the size of a fingernail, with 2,300 transistors. It ran at 740 thousand clock ticks a second and worked on just 4 bits at a time. It was built for a Japanese desk calculator, the Busicom 141-PF.

These lessons teach you to program that chip. You will read two small programs written in 4004 assembly language. You will see how each line turns into the bytes the chip actually runs, and you will follow what the chip does with every one of those bytes. You run the programs on the emulator in this project, so you do not need a real 4004.

Before You Start

You need Python 3.10 or newer. Open a command prompt in the main folder of this project, the folder that has the i4004 and examples folders in it. Check that the emulator works by typing this and pressing Enter:

python -m i4004 run examples/hello.asm --console --accessible

The first line you hear should be:

Output: HELLO, WORLD! THE 4004 TURNS 55 TODAY.

After that the emulator describes where the chip stopped and what was left in its registers.

A note on screen readers. Every command in these lessons can take the --accessible option, which you can shorten to -a. It makes the emulator talk in short, plain sentences instead of packed columns of hex. If you want it on all the time, set the environment variable I4004_ACCESSIBLE to 1.

Assembly code uses a lot of punctuation, such as commas, colons and semicolons, so set your screen reader to read all punctuation while you work through these lessons. In the walkthroughs, each instruction has its own heading. Use your screen reader's heading key to move from one instruction to the next.

The Lessons

  1. Meet the 4004. What is inside the chip: nibbles, hex, the accumulator, registers, ROM, RAM and ports. Also how an assembly line becomes bytes. Read this one first.
  2. Hello, World on a 4-Bit Chip. A line-by-line walkthrough of examples/hello.asm. The 4004 can only send 4 bits at a time, so how does it print letters? This lesson shows you.
  3. Adding Like a Calculator. A line-by-line walkthrough of examples/bcd_add.asm. This program adds two 8-digit numbers in decimal, the job the 4004 was invented to do.

Reference

The README.md file in the main folder lists every command-line option, the full assembly language syntax and the debugger commands. The lessons explain things as they come up, so you do not need to read the README first.
